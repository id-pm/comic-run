# Comic Run

Comic Run is a fast-paced endless runner game for PC, developed in Unity 3D during **Game Jam 2024**.

The player takes on the role of a character spreading a “comic” gas that makes civilians laugh.  
The goal is to score as many points as possible while managing limited resources and avoiding constant police pursuit.

## 🔍 Project Overview
- **Platform:** PC
- **Engine:** Unity (2021.3.30f1)
- **Language:** C#
- **Genre:** Endless Runner, Action

## 🎮 Core Gameplay
- Endless running on a map
- Spray civilians with comic gas to make them laugh and earn points
- Avoid police officers that continuously chase the player
- Limited gas supply that must be refilled using gas canisters
- Night mode toggle available in settings for visual variety
- The game ends **only when the player is caught by the police**
- Objective: achieve the highest possible score

## 🎯 Gameplay Mechanics
- Resource management (comic gas)
- Increasing pressure from pursuing enemies
- Continuous forward movement and obstacle avoidance
- Dynamic camera system with smooth transitions between menu, tutorial, leaderboard, and player views
- Night mode toggle available in settings for visual variety

## 🕹 Controls
- Keyboard-based movement
- Comic gas is automatically applied when near civilians
